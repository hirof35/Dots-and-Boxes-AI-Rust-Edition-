Dots and Boxes AI (Rust Edition)
Rustと言語の学習および、強力な探索アルゴリズムの実験を目的として作成された、GUI版「ドット・アンド・ボックス」ゲームです。

🎮 ゲームの概要
ドット・アンド・ボックスは、点（ドット）を繋いで線を引き、4辺を囲んで「ボックス」を作ったプレイヤーがそのスコアを獲得する伝統的なボードゲームです。ボックスを完成させると、同じプレイヤーが続けて線を引くことができます。

✨ 特徴
高性能AI: Minimax法とAlpha-Beta枝切りを駆使したAIを搭載。

可変難易度: 探索の深さをリアルタイムで調整可能（1〜8手先）。

リアルタイム統計: AIの思考時間、探索ノード数、処理速度（nodes/s）を表示。

直感的な操作: 青（人間）と赤（AI）の色分けによる視認性の向上。

Undo機能: Ctrl+Z または画面上のボタンで直前の手（AIの手を含む）を巻き戻せます。

Rustによる高速処理: 計算負荷の高い探索を効率的に実行。

🛠 使用技術
Language: Rust 2021 edition

GUI Framework: egui (eframe)

Time Measurement: instant (高精度タイマー)

WinAPI: Windows環境での最適化

🚀 セットアップと実行
1. 準備
Rustツールチェーン（cargo）がインストールされていることを確認してください。

2. ビルドと実行
プロジェクトのルートディレクトリで以下のコマンドを実行します。

Bash
cargo run --release
※AIの探索速度を正確に計測するため、--release フラグを付けて実行することを強く推奨します。

🕹 操作方法
線を引く: ドットとドットの間のグレーの領域をクリックしてください。

Undo: ミスをした場合は ⟲ Undo ボタンまたは Ctrl + Z を押してください。

リセット: ゲームを最初からやり直す場合は ♻ リセット ボタンを押してください。

⚙️ AI設定の目安
左側のサイドパネルにある「探索の深さ」スライダーで調整できます。

1〜3: 初級（ほぼ瞬時に反応します）

4〜6: 中級（標準的な強さです）

7〜8: 上級（1秒以上の思考を要する場合があり、非常に手強くなります）
